# Pachycephalosaurus – Genetics

Skins that are considered mutations for Pachycephalosaurus include: Albino, Melanistic, DR Gynandromorphism Mutation, DR Pseudo Mela Mutation, DR Iridescent Mutation, DR Leucistic Mutation, DR Piebald Mutation, DR Super Dalmatian Mutation, DR Axanthic Mutation, DR Pied Macaw, DR Melanistic, DR Albino. Players must roll in 🎲・genetics-rolls to use these skins in game. This is one roll per species, per character. Only when the character dies can you roll again if using the same character name. DR Gynandromorphism Mutation - Individuals with this skin are considered male and treated as such. If the character is a female, she still follows female behavior. Mutations with no bright color - Males with mutations that lack bright colors are considered "non-dimorphic males". These males are infertile and have no desire to breed. Non-dimorphic males are treated as a female by other Pachycephalosaurus due to their appearance.
