# Anodontosaurus – Profile Specific Feature

Anodontosaurus can develop a profile specific illness, showcased by wearing the Gastroenteritis Infection skin from the Dynasty Morph Skins mod. Anodontosaurus that consume the same food type (flowers, fruit, roots, nuts) for longer than one in-game day cycle become sick with Gastroenteritis Infection. Only after the skin has shed and the player has eaten another food type can the player move past the illness.
