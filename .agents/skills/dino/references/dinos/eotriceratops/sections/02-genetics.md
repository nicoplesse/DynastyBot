# Eotriceratops – Genetics

Skins that are considered mutations for Eotriceratops include: Albino, Melanistic, DR Leucistic Mutation, DR Piebald Mutation, Vita Pied Minor, Vita Pied Major, Vita Gyandromorph Players must roll in 🎲・genetics-rolls to use these skins in game. This is one roll per species, per character. Only when the character dies can you roll again if using the same character name.
