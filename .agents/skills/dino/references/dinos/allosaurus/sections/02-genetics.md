# Allosaurus – Genetics

Skins that are considered mutations for Allosaurus include: Albino, Melanistic, DRM Mela, DRM Pied Anaconda, DRM Pseudo Mela, DRM Leucistic Players must roll in 🎲・genetics-rolls to use these skins in game. This is one roll per species, per character. Only when the character dies can you roll again if using the same character name.
