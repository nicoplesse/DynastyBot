# Server Rules – Einleitung

The following set of rules applies to our in-game server, and should be followed in tandem with our Discord Rules, which form part of our player Code of Conduct.  All waystones and in game caves have been disabled on this server. When referring to body lengths, we use the standard measurement of 1 body length is equivalent to 1 Parasaurolophus body length from nose-tip to tail-tip. If you are playing a Giant species, please use common sense and move further away if it is not obvious that you are unengaged from a nearby conflict.
